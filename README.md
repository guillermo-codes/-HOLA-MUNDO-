# Hola, mundo

> Un pequeño recorrido por el programa que suele dar la bienvenida a quienes empiezan a programar.

**Hola, mundo** es un proyecto personal de práctica web. La página explica qué es este primer programa, repasa parte de su historia y compara cómo se muestra el mismo mensaje en distintos lenguajes.

El objetivo del proyecto es aprender construyendo: mejorar la estructura con HTML, dar forma a la interfaz con CSS y utilizar una pequeña interacción con JavaScript.

## Vista general

- **Tema:** historia y significado del programa “Hola, mundo”.
- **Tipo:** página web informativa y adaptable.
- **Estado:** proyecto de aprendizaje en desarrollo.
- **Autor:** Guillermo Contreras.

## Características

- Contenido organizado con elementos semánticos de HTML.
- Navegación interna para llegar a cada sección.
- Diseño adaptable a pantallas pequeñas y grandes.
- Modo claro y oscuro mediante un botón.
- Ejemplos de código en Python, JavaScript y C++.
- Tabla con encabezados accesibles y sección de fuentes.
- Estilos de foco visibles para facilitar la navegación con teclado.
- Respeto por la preferencia del sistema de movimiento reducido.

## Tecnologías

| Tecnología | Uso en el proyecto |
| --- | --- |
| **HTML5** | Estructura, contenido, navegación, imágenes y tabla. |
| **CSS3** | Diseño visual, distribución, colores, modo oscuro y adaptación a diferentes pantallas. |
| **JavaScript** | Interacción del botón que alterna el tema claro y oscuro. |

## Cómo ejecutar el proyecto

No necesita instalar dependencias ni utilizar un framework.

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo \`index.html\` en tu navegador.

También puedes utilizar la extensión Live Server de Visual Studio Code para visualizar los cambios mientras trabajas.

## Qué estoy practicando

Este proyecto forma parte de mi proceso de aprendizaje de desarrollo web. Lo utilizo para reforzar:

- HTML semántico y organización del contenido.
- Accesibilidad básica y buenas prácticas en formularios, enlaces, imágenes y tablas.
- Selectores, propiedades y valores de CSS.
- Modelo de caja, espaciado y distribución de elementos.
- Diseño responsive y estados visuales.
- Lectura, revisión y mantenimiento de código.

## Alcance

El botón de tema cambia la apariencia de la página mientras está abierta. **La preferencia no se guarda después de recargar el navegador**, porque todavía no se ha implementado esa característica.
