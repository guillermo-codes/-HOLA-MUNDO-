PRIMEROS PASOS EN PROGRAMACIÓN

Hola, mundo.

Dos palabras sencillas. Una tradición que ha acompañado a generaciones de programadores.

¿Qué significa? Su historia Por qué importa Ejemplos

01 / EL CONCEPTO

¿Qué es “Hola, mundo”?

“Hola, mundo” es un programa pequeño que muestra un mensaje en la pantalla o en la consola. Suele ser uno de los primeros ejercicios al aprender un lenguaje de programación porque permite comprobar, de forma sencilla, que podemos escribir una instrucción y obtener un resultado.

La idea es simple: el programador escribe una orden y la computadora la ejecuta. En este caso, la orden consiste en mostrar un texto.

Ejemplo en Python 
print("¡Hola, mundo!")
**Una aclaración:** este ejemplo confirma que una instrucción básica puede ejecutarse y producir una salida. No comprueba por sí solo que todo el entorno de desarrollo esté configurado correctamente.

02 / EL RECORRIDO

¿De dónde viene esta tradición?

La historia no tiene un único momento mágico. Brian Kernighan utilizó un ejemplo con las palabras “hello” y “world” en un tutorial del lenguaje B a comienzos de los años setenta. Después apareció una versión para C en un memorando de Bell Labs. La tradición se extendió ampliamente cuando el ejemplo llegó al libro The C Programming Language, publicado en 1978 y escrito por Brian Kernighan y Dennis Ritchie.

  1. 1972

    Un ejemplo en el lenguaje B

    Kernighan empleó las palabras “hello” y “world” en un tutorial introductorio. Era un ejemplo didáctico, no todavía la versión moderna más conocida.

  2. 1974

    Una versión para C

    El memorando de Bell Labs Programming in C: A Tutorial incluyó una versión del programa en el lenguaje C.

  3. 1978

    El ejemplo se vuelve famoso

    El libro The C Programming Language ayudó a convertir el saludo en una referencia para quienes comienzan a programar.

03 / EL VALOR DEL PRIMER PROGRAMA

¿Por qué importa escribir “Hola, mundo”?

Porque es el momento en que una idea deja de estar solo en nuestra cabeza y se convierte en un resultado que podemos ver. Escribes una instrucción, la ejecutas y la computadora responde mostrando un mensaje. Parece algo pequeño, pero ahí empiezas a entender la relación entre el código que escribes y lo que la máquina hace.

Para quien está aprendiendo, este ejercicio permite familiarizarse con la sintaxis de un lenguaje, el editor de código, la ejecución de un programa y la salida que aparece en pantalla. También ofrece una primera oportunidad para detectar errores sencillos, corregirlos y volver a probar.

“Hola, mundo” no te enseña a programar por sí solo ni demuestra que ya dominas un lenguaje. Su importancia está en que ofrece un comienzo sencillo y comprobable. A partir de ese primer resultado puedes avanzar hacia conceptos más complejos, como las variables, las condiciones, los ciclos y la interacción con el usuario.

Al final, lo importante no es el saludo que aparece en pantalla: es descubrir que puedes darle instrucciones a una computadora, observar lo que ocurre y aprender a mejorar tu solución.

04 / EN DISTINTOS LENGUAJES

El mismo mensaje, distintas instrucciones

El resultado puede ser el mismo, aunque cada lenguaje tiene su propia sintaxis, es decir, sus propias reglas para escribir instrucciones.

Comparación de instrucciones básicas
Lenguaje Instrucción
Python print("¡Hola, mundo!")
JavaScript console.log("¡Hola, mundo!")
C++ std::cout << "¡Hola, mundo!";
