# El Lore del "Hola Mundo" 

Este es mi primer proyecto de desarrollo web. Nació de una curiosidad personal: **¿por qué todos los programadores del mundo empezamos con la misma frase?**

Más que un simple ejercicio de "copiar y pegar", decidí investigar el origen histórico de este rito de iniciación y construir una página web para documentarlo.

##  Tecnologías utilizadas
- **HTML5:** Estructura semántica (uso de `<header>`, `<main>`, `<section>`, `<table>` y `<form>`).
- **CSS3:** Diseño limpio, adaptable a pantallas y con un sistema de **Modo Oscuro/Claro**.
- **JavaScript:** Manipulación del DOM para alternar el tema y guardar la preferencia del usuario usando `localStorage`.

## Características
- Artículo documentado con las fuentes reales de la historia del "Hola Mundo".
- Tabla comparativa de cómo se escribe este programa en diferentes lenguajes.
- Diseño interactivo y accesible.
