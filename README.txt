# Hola Mundo - Proyecto Web

Este es mi primer proyecto front-end. Está diseñado y programado aplicando los fundamentos básicos de HTML, CSS y JavaScript.

## Tecnologías utilizadas
- HTML5 semántico
- CSS3
- JavaScript Vanilla (lo mínimo necesario para que funcione)

## Características
- Código estructurado y limpio.
- Diseño adaptable (responsive) para PC y celulares.
- Funcionalidad interactiva con modo claro y modo oscuro.
